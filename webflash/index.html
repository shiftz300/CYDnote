CYDnote 在线刷机

适用于 ESP32-2432S028/ESP32-2432S028R (CYD)。请使用支持 Web Serial 的 Chrome/Edge，并通过 USB 连接设备。

当前模式：保留数据更新（不会覆盖 0x310000 的 LittleFS 分区）。
  • 若自动进入下载模式失败，请按住 BOOT，再点一次 RESET 后重试。
  • “保留数据更新”仅在分区表未变化时才能可靠保留既有数据。
  • 发布此页面时，请把编译得到的 bootloader.bin、partitions.bin、firmware.bin、littlefs.bin 与本页放在同一目录。

本页使用 ESP Web Tools；manifest 已按本仓库的分区表和 LittleFS 偏移配置好。
