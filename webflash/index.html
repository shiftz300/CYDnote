📌Quick notes

  • Safe update is the recommended option for normal upgrades.
  • Factory restore is only for first-time setup or full recovery.
  • The page reads firmware from the repository release tag latest.
  • The build date shown below comes from the firmware asset upload time, not only the release publish time.
  • If the GitHub API cannot be reached, the page falls back to safe update mode.
  • Backups are saved locally in your browser as a downloadable file.
