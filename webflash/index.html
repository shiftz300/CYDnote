CYDnote 在线刷机

适用于 ESP32-2432S028/ESP32-2432S028R (CYD)。请使用支持 Web Serial 的 Chrome/Edge，并通过 USB 连接设备。

当前模式：保留数据更新（不会覆盖 0x310000 的 LittleFS 分区）。

正在读取 GitHub Release 构建文件…

  • 若自动进入下载模式失败，请按住 BOOT，再点一次 RESET 后重试。
  • “保留数据更新”仅在分区表未变化时才能可靠保留既有数据。
  • 本页会直接读取 GitHub Releases 中 latest 标签下的构建产物，无需再把 bin 文件放到网页目录。
  • 如果在国内访问 GitHub 下载较慢，可勾选上方的 ghproxy 镜像加速。

本页使用 ESP Web Tools；manifest 已按本仓库分区表配置，并直接指向 GitHub Release 产物。
